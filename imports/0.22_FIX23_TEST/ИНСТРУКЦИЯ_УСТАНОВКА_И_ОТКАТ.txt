FHD ONLINECHAT 0.22 FIXED — ИНСТРУКЦИЯ ПО УСТАНОВКЕ И СПИСОК ИСПРАВЛЕНИЙ
========================================================================

ЧТО ИСПРАВЛЕНО В ВЕРСИИ 0.22 FIXED (ПО СРАВНЕНИЮ С 0.22 TEST5):
1. [КРИТИЧЕСКОЕ] Исправлен немедленный вылет игры (Access Violation 0xC0000005)
   при запуске и при отправке сообщений из-за сломанного стаба _chkstk
   (в TEST5 функция _chkstk по адресу 0x10014D54 проверяла страницы стека,
   но НЕ выделяла кадр стека ESP -= EAX для netthread на 34 724 байта
   и FHDChat_SendToW на 14 112 байт, что приводило к записи поверх вершины
   стека и разрушению ESP).
2. [СТАБИЛЬНОСТЬ] Исправлено нечётное смещение указателя стека (sub esp, 1 /
   add esp, 1 -> sub esp, 4 / add esp, 4) в функции расчёта геометрии
   оверлея apply_geometry (0x1000EF10), нарушавшее 4-байтное выравнивание
   стека Windows x86.
3. [ЗАЩИТА ПАМЯТИ] В функцию FHDChat_NameCollisionW (0x10004780) добавлена
   проверка входного указателя на NULL перед чтением строки в спинлоке.
4. [ТАБЛИЦА ЭКСПОРТА PE32] Пересобрана таблица экспорта DLL:
   - Внутреннее имя модуля в заголовке экспорта исправлено с временного
     'built2.dll' на 'FHDOnlineChat.XenoPlugin.dll'.
   - Для всех 4 новых функций версии 0.22 (FHDChat_NameCollisionW,
     FHDChat_OpenUpdateLink, FHDChat_OurIdentityW, FHDChat_PeerOrdinal)
     добавлены все 3 формы экспорта (Func, Func@N, _Func@N) — итого 63
     отсортированных символа экспорта.
   - Рассчитана и записана корректная контрольная сумма PE CheckSum (0x0002911B).
5. [ СТРУКТУРА АРХИВА И ВЕРСИИ] Внутренние строки версии синхронизированы
   ('0.22-fixed-native021'), убран дубликат файла инструкции из корня архива,
   добавлена папка SOURCE с обновлёнными файлами определений экспорта и
   исходным кодом.

КАК УСТАНОВИТЬ:
1. Полностью закрой игру.
2. Удали старую папку Mods\OtherMods\FHD_OnlineChat (при необходимости
   сохранив резервную копию вне папки Mods).
3. Распакуй архив FHD_OnlineChat_v0.22_FIXED.zip в корневую папку игры
   (там, где лежит Rangers.exe).
4. Убедись, что файл плагина находится по пути:
   Mods\OtherMods\FHD_OnlineChat\Native\FHDOnlineChat.XenoPlugin.dll
5. Запусти игру и включи мод FHD_OnlineChat в списке модов.

УПРАВЛЕНИЕ В ИГРЕ:
- F12 — скрыть / показать окно чата (в планетарных боях скрывается само).
- Enter — начать ввод сообщения / отправить сообщение.
- Esc — отменить ввод.
- Мышь / Стрелки / Home / End / Backspace / Delete — управление курсором.
- Ctrl+A / Ctrl+C / Ctrl+V — выделение, копирование и вставка текста (до 500 символов).

# FHD OnlineChat 0.22 FIX23 — исходники / Nexus-style source snapshot

**Статус: TEST, не проверено в игре.** Здесь сохранены все **17** текстовых файлов каталога SOURCE и ещё **3** вспомогательных файла (INI, инструкция, BUILD_ID) из `FHD_OnlineChat_0.22_FIX23 TEST.zip` на [Google Drive](https://drive.google.com/file/d/1MmcxyeAnziTpLhv54isczUvIrns0ygKF/view?usp=drivesdk), без изменения байтов. Сравнение с ZIP: **20 из 20 точных совпадений по Git blob SHA/SHA-256**, включая 17 исходников и 3 вспомогательных файла.

## Содержимое

- `SOURCE/`: C-код клиента, серверный код Cloudflare, заголовки, ресурсы шрифта, заметки о сборке, скрипты преобразования.
- `SHA256SUMS.txt`: контрольные суммы всех исходников.
- `verify_source.py`: автоматическая локальная проверка SHA-256; GitHub Actions запускает тот же тест.

Готовый DLL и файлы `.cmd` **не переносились**; они остаются в архиве готового мода на Drive. `ModuleInfo.txt` восстановлен из оригинального UTF-16LE с BOM в редактируемый `ModuleInfo.utf8.txt`; проверка точного обратного преобразования вынесена в `verify_moduleinfo_rebuild.py`.

## Проверка

```sh
python 1FHD_OnlineChat_0.22_FIX23_Nexus-GitHub/verify_source.py
```

Скрипты исходника могут выполнять сборку или патчинг **отдельного тестового файла**, но сами по себе эта загрузка и QA-проверка не меняют игровую папку и не запускают игру.

## Требования к дальнейшей разработке

- Любая зависимость от `Rangers.exe`: поддержка обоих EXE с определением по SHA-256 автоматически.
- TEST ↔ RELEASE: переключение в обе стороны; выбор версии по имени ZIP не означает, что переключатель реализован.
- Проверка `DLL`, встроенной механики и поведения в игре обязательна перед выпуском RELEASE.
- Реальные токены и секреты не коммитить: только публичные идентификаторы и имена переменных окружения.
- Старые версии 0.18/0.21 хранятся отдельно и этим импортом не заменены.
